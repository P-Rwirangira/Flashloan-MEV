# Development Rules

## After Each Feature Implementation

1. **Run Type Check**
   ```bash
   npm run typecheck
   ```

2. **Fix All Errors**
   - Address all type errors
   - Fix compilation issues
   - No warnings should remain

3. **Handle Unused Variables**
   - Remove if truly unused
   - Integrate into logic if needed
   - Prefix with underscore if intentionally unused

4. **Commit Changes**
   - Single sentence commit message
   - No emojis
   - Format: `type: description`
   
   Examples:
   - `feat: Platform integration`
   - `fix: Gas price calculation`
   - `refactor: Risk controller logic`
   - `chore: Update dependencies`

## Commit Types

- `feat`: New feature
- `fix`: Bug fix
- `refactor`: Code restructuring
- `chore`: Maintenance tasks
- `docs`: Documentation only
- `test`: Test additions or fixes
